# Prompt and LLM Instruction References

This folder contains reusable prompt patterns and role-specific instruction
references. They are research inputs, not active Codex, Claude, or OpenCode
configuration and do not override `AGENTS.md`.

- `code-reviewer.md` - review prompt/reference.
- `code-simplifier.md` - simplification prompt/reference.
- `python-patterns.md` - Python authoring patterns.

Use `../instructions/` for project-specific active instruction drafts. Keep an
instruction here only when it is a reference artifact rather than an active
repository rule or a discoverable agent skill.
