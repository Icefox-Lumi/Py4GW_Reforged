# Py4GW AI Guidance

This directory is the authoritative detailed guidance for Py4GW engineering
agents. `AGENTS.md` is intentionally lean: it supplies the always-on control
plane and routes work here before detailed action.

## Current Guides

- `operating-model.md` - identity, evidence, planning, execution,
  communication, and reporting.
- `change-control-and-verification.md` - editing, Git safety, migration,
  testing, and builds.
- `engineering-practices.md` - code quality, architecture, configuration,
  security, platform, and project coverage.
- `runtime-conventions.md` - injected script lifecycle and PyImGui rules.
- `project-context.md` - project-specific paths, owners, migration, RE,
  bridge, widget, and runtime context.

## Supporting Material

- `reference/` contains reusable prompt and authoring references.
- `research/` contains dated agent-workflow research.
- `source-archive/` and `source-archive.md` preserve external instruction
  sources used for comparison.
- `instruction-history/` preserves predecessor drafts and recovery records;
  it is historical, not current instruction authority.

For documentation structure and naming, also read
`../maintenance/documentation-style-guide.md`.
