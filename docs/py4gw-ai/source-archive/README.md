# Instruction Source Archive

This folder preserves external and historical instruction-source material used
while drafting the Py4GW instruction system. It is provenance, not active
configuration.

- `source_codex_*` - Codex-source references.
- `source_opencode_*` - OpenCode-source references.

Read the parent folder's `README.md` and current repository `AGENTS.md` before
using any of these records. Never copy an external source wholesale into the
project instructions without reconciling it with Py4GW ownership and runtime
constraints.
