# Map Overlay Merge Documentation

This folder preserves the map-overlay merge analysis and staged design.

1. `analysis.md` - context and problem framing.
2. `feature-inventory.md` - feature union inventory.
3. `package-shape.md` - proposed package design.
4. `build-status.md` - recorded implementation status.

The current overlay and UI source remains authoritative; use these records to
understand intent, not as proof that a planned merge is complete.
