# Map Overlay Merge Documentation

This folder preserves the map-overlay merge analysis and staged design. The
design-phase records are archived; the build-status record remains live.

  what remains for in-client verification).
- `../../archive/ui/map-overlay/` - `analysis.md`, `feature-inventory.md`, and
  `package-shape.md`, the superseded design-phase records; see
  `../../archive/README.md`.

The current overlay and UI source remains authoritative; use these records to
understand intent, not as proof that a planned merge is complete.
