# LaunchSurface Documentation Map

Status: historical topic. The LaunchSurface framework was replaced by the
current `launch_bar` package (`Py4GWCoreLib/py4gwcorelib_src/launch_bar/`),
hosted from `Py4GW_widget_manager.py`.

The framework design, authoring guides, user manual, and runtime/UI audits are
preserved for provenance under `../../archive/ui/launch-surface/`; see
`../../archive/README.md` for the full retired-material index.

## Contradiction rule

- Treat the archived design as the intended architecture of the removed
  predecessor, not proof that any feature is live.
- Current source and injected-client evidence are authoritative for current
  behavior; compare with the archived records only when LaunchSurface
  migration or compatibility history is in scope.
- The predecessor's model/host/manager split informed the current
  `launch_bar` design; see `../launch-bar/README.md`.
