# Widget Manager Documentation

This directory contains the widget discovery, metadata, handler, catalog, and
alternate-UI integration reference.

- `widget-manager-and-catalog.md` is the primary documentation reference for
  `WidgetHandler`, widget discovery, metadata defaults, and `WidgetCatalog`.
- Current implementation under `Py4GWCoreLib/` and `Widgets/` outranks this
  guide when behavior or ownership has changed.
- This is distinct from LaunchBar/LaunchSurface UI implementation records;
  those surfaces consume or present widget data but do not own discovery.
