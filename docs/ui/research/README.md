# UI Research

This topic owns native UI investigation that supports the UI subsystem. These
records are research evidence, not an independent `RE` taxonomy.

- `probes/` contains reproducible native UI probes.
- `probes/tools/` contains probe scripts; `probes/generated/` contains their
  captured output.
- `tools/` contains general UI-research helpers.
- `generated/` contains generated UI reference data.
- `archive/` preserves superseded captures and backups.

Use the owning native source and live injected-client reproduction to determine
current behavior.
