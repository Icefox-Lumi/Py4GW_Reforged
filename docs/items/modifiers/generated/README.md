# Item-Mod Catalog Data

This folder contains generated and captured item-mod catalogs used by the item
modifier research and API design. Read `../README.md` and the cited numbered
record before relying on a catalog.

- `mod-parity-scan.txt` is the live output of the in-client `Mod Parity Scan`
  debug widget (`Widgets/Coding/Debug/Py4GW/Mod Parity Scan.py`); it
  regenerates on every run and its conclusions live in `item-mods-api.md` and
  `game-mod-table.md`.
- `single-item-dump.txt` and `mod-naming-audit.txt` are superseded captures,
  preserved under `../../archive/items/modifiers/generated/`.

Do not hand-edit generated catalog data. Refresh it through the documented
tools and widgets and record the game build, source address, and extraction
method.
