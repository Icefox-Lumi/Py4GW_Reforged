# Loot Redesign Documentation

This folder records the proposed replacement for the loot system.

1. `index.md` - document order and scope.
2. `class.md` - design of the loot class.
3. `implementation-spec.md` - implementation specification.
4. `filter-structure.md` - the active filter-domain contract (evaluation →
   filter → filter set; no profile layer) for the Loot Filter Factory and its
   consumers.

Treat these as design and migration evidence. Confirm the current owner and
implementation status in source before changing gameplay behavior.
