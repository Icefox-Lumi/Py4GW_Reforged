# Conceptual Architecture Documentation

This directory contains the canonical conceptual model for Py4GW.

- `Py4GW_Conceptual_Model.md` defines the project layer stack, source-of-truth
  boundaries, role groups, and terminology.
- `Py4GW_Model_Features_Detail.txt` is a derived quick-scan export; it is not a
  separate authority.
- Current implementation, native bindings, and runtime evidence outrank this
  model when the model is stale or incomplete.
- Use the model to orient architecture work, then verify affected symbols and
  ownership in the current source.
