# Architecture Governance Documentation

This directory contains review and migration guidance for preserving
ownership, source traceability, and understandable changes.

- `pr-review-traceability-and-migration-analysis.md` is a review procedure and
  decision record for additive, reversible, source-preserving changes.
- It governs how changes are reviewed; it does not replace subsystem-specific
  implementation documentation or current source evidence.
