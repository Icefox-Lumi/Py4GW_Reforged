# Game Client Documentation

This topic owns evidence about Guild Wars client behavior that is not specific
to one user-interface or gameplay subject. Current source, native patterns,
and live-client reproduction remain authoritative over these records.

- `research/` contains game-client investigations, mappings, and methodology.
- `research/archive/` preserves superseded captures and backups as historical
  evidence.

For UI-specific native research, use `../ui/research/`; for item-modifier
research, use `../items/modifiers/`.
