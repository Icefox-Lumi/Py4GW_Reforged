# Automation Documentation

Use this directory for gameplay automation and authoring records.

- `behavior_trees/` — behavior-tree runtime, metadata, and bot-authoring.
- `builds/` — build controllers, skill contracts, and build-workflow guidance.
- `heroai/` — HeroAI combat, interrupt, UI, and follower behavior.
- `hex_removal/` — hex-removal configuration, selection, and coordination.

Inspect the owning source and runtime evidence before treating a record as
current behavior.
